# 소리노트 · 사진 한 장, 바로 듣기

일본어·한국어·영어 사진을 찍거나 올리면 글자를 추출하고 단락별로 읽어주는 무료 웹 프로그램입니다.

## 바로 듣는 화면

- 사진 촬영·선택 시 자동 글자 인식
- 단락 하나만 듣기 또는 전체 이어 듣기
- 전체 재생 일시정지·이어 듣기·정지, 0.75/1.0/1.25배속
- 본문 수정 및 빈 줄로 단락 나누기
- 새 사진 선택 시 이전 인식·본문·재생 상태 정리
- ‘처음부터 새로’로 사진·본문·인식 작업·재생 모두 초기화
- 보관함·제목·저장·백업·로그인 기능 없음

사진과 본문은 메모리에서만 처리하며 새로고침하거나 닫으면 사라집니다. 이전 버전에서 저장한 자료를 자동으로 지우지는 않습니다. OCR 엔진의 언어 파일은 브라우저에 캐시될 수 있습니다.

## 일본어 인식 개선

- 고정 버전의 공식 tessdata_best 가로·세로 모델을 사용합니다. 기존 정수 모델 캐시와 이름을 분리했습니다.
- 일본어의 글 방향은 자동·혼합, 가로쓰기, 세로쓰기 중에서 선택합니다. 자동·혼합은 두 모델을 함께 불러와 가로 제목과 세로 본문을 처리합니다.
- OCR에는 JPEG로 재압축한 미리보기 대신 원본에서 만든 무손실 캔버스를 전달합니다. 작은 사진은 최대 2배 확대하고, 휴대폰 메모리를 고려해 약 600만 화소·긴 변 3600px 이내로 제한합니다.
- 흰 여백과 약한 기울기 보정을 적용하며, 큰 각도로 잘못 추정한 경우 원래 방향으로 다시 읽습니다.
- 인식된 글 영역을 유지하고 줄·열 간격과 들여쓰기로 단락을 복원합니다. 세로쓰기는 오른쪽 열부터 읽습니다.
- 바르게 놓인 가로 본문의 불확실한 줄은 원본에서 최대 6줄까지 재검사합니다. 문장 길이와 편집 거리, 인식 신뢰도를 비교해 작은 개선만 채택하며, 특정 교재의 정답이나 단어 치환표를 사용하지 않습니다. 세로 본문과 크게 기울어진 사진은 이 추가 재검사에서 제외합니다.
- 독립된 생략 표시와 마지막의 명확한 괄호형 출처를 본문에서 구분합니다. 위치와 내용을 따로 표시하고 전체·단락 듣기에서는 제외합니다. 문장 속 괄호와 인용문은 유지합니다.
- 짧은 일본어 인용문의 닫는 괄호가 세로 막대로 읽힌 경우에 한해 인용부호 짝을 복원합니다. 괄호가 맞는 인용문 안의 막대와 직접 입력한 본문은 이 보정에서 제외합니다.
- 정밀 모델은 첫 다운로드와 실행에 시간이 더 필요합니다. 원근 왜곡, 작은 후리가나, 흐린 글자, 손글씨 등에서는 오류가 남을 수 있습니다.

가로쓰기·세로쓰기·혼합 지면의 생성 테스트 이미지를 실제 브라우저에서 검증했습니다. 가로쓰기 58자 테스트 한 장에서는 이전 버전의 편집 거리 8이 개선 후 0이었습니다(공백 제외). 이 수치는 해당 테스트 사진의 비교이며 전체 사진의 정확도를 보장하지 않습니다. 비교 텍스트와 실제 OCR 좌표는 tests/fixtures에 있습니다.

사용자가 제공한 실제 교재 사진으로 추가 검증했습니다. 개인 교재 이미지, 원문 전사와 OCR 전문은 저장소에 포함하지 않습니다. 작은 문항 번호, 워터마크와 밑줄에 닿은 괄호는 오류가 남을 수 있습니다.

## Netlify

이 저장소의 main 브랜치를 Netlify와 연결합니다. 루트의 netlify.toml이 게시 폴더 sorinote를 지정합니다. 별도 빌드 명령·환경 변수·유료 API 키는 필요 없습니다. main에 수정 내용을 커밋·푸시하면 연결된 사이트가 새 버전을 배포합니다. Netlify 무료 요금제의 사용량 한도가 적용됩니다.

## 인식과 음성

Tesseract.js 6.0.1을 브라우저에서 실행합니다. 사진이나 본문을 자체 서버로 업로드하지 않습니다. 초기 엔진·언어 파일 다운로드에 인터넷이 필요합니다. 단락은 인식된 지면 배치로 구분하며, 틀린 글자나 단락은 ‘글 수정’에서 고칠 수 있습니다. 사진과 본문을 클라우드나 브라우저 저장소에 보관하지 않습니다.

Web Speech API로 기기·브라우저의 목소리를 사용합니다. 각 언어의 음성을 설치해야 할 수 있습니다. 목소리에 따라 브라우저 제공사의 온라인 음성이 사용될 수 있으며, 화면 잠금·백그라운드 동작은 기기마다 다릅니다. MP3 다운로드와 번역은 제공하지 않습니다.

## 검증

Node.js가 있으면 다음 명령으로 단락 분리, 긴 문장 재생 분할, 단락 단독·전체 재생, 초기화 뒤 오래된 이벤트 무시, 일시정지와 예약 재생 취소를 검증할 수 있습니다.

```sh
node --test tests/core.test.cjs
```

정적 HTML·CSS·JavaScript이며 설치·빌드 없이 sorinote 폴더를 게시합니다. 자세한 사용법은 sorinote/guide.html에 있습니다.
