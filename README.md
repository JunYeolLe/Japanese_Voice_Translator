# 소리노트 · 사진과 글, 바로 듣기

일본어·한국어·영어 사진을 찍거나 글을 붙여넣어 단락별로 읽어주는 무료 웹 프로그램입니다.

## 바로 듣는 화면

- 사진 촬영·선택 후 드래그·슬라이더로 본문 선택 또는 전체 사진 인식
- 단락 하나만 듣기 또는 전체 이어 듣기
- 전체 재생 일시정지·이어 듣기·정지, 0.5~2.0배속 슬라이더(0.05배 간격)
- 본문 수정 및 빈 줄로 단락 나누기
- 한자 위 후리가나 켜기·끄기, 표시된 독음 수정, 첫 사용 때만 사전 준비
- 후리가나와 주석이 섞이지 않는 본문 전체 복사
- 본문 글자 크기 작게(14px)·보통(15px)·크게(17px)
- 선택 단락 반복 듣기와 현재 읽는 문장 강조
- 새 사진 선택 시 이전 인식·본문·재생 상태 정리
- ‘처음부터 새로’로 사진·본문·인식 작업·재생 모두 초기화
- 보관함·제목·저장·백업·로그인 기능 없음

사진과 본문은 메모리에서만 처리하며 새로고침하거나 닫으면 사라집니다. 이전 버전에서 저장한 자료를 자동으로 지우지는 않습니다. OCR 엔진의 언어 파일은 브라우저에 캐시될 수 있습니다.

## 일본어 인식 개선

- 고정 버전의 공식 tessdata_best 가로·세로 모델을 사용합니다. 기존 정수 모델 캐시와 이름을 분리했습니다.
- 일본어의 글 방향은 자동·혼합, 가로쓰기, 세로쓰기 중에서 선택합니다. 자동·혼합은 두 모델을 함께 불러와 가로 제목과 세로 본문을 처리합니다.
- OCR에는 JPEG로 재압축한 미리보기 대신 원본에서 만든 무손실 캔버스를 전달합니다. 작은 사진은 최대 2배 확대하고, 휴대폰 메모리를 고려해 약 600만 화소·긴 변 3600px 이내로 제한합니다.
- 흰 여백과 약한 기울기 보정을 적용하며, 큰 각도로 잘못 추정한 경우 원래 방향으로 다시 읽습니다.
- 인식된 글 영역을 유지하고 줄·열 간격과 들여쓰기로 단락을 복원합니다. 세로쓰기는 오른쪽 열부터 읽습니다.
- 긴 밑줄 선을 제외하고, 작은 인쇄 후리가나는 본문 바로 위·세로 본문 오른쪽의 크기와 위치로 구분합니다. 작은 원형 문항 표시는 테두리와 안쪽 숫자를 함께 확인합니다. 일본어 の·。·一·ー와 날짜·금액·소수는 보존하는 조건을 검증합니다.
- 인쇄 후리가나·문항 표시를 분리한 뒤 다시 인식하되 한자가 많이 사라지거나 신뢰도가 낮아진 결과는 채택하지 않습니다. 작은 기울기는 Tesseract가 회전한 실제 화상과 같은 좌표로 분석합니다.
- 큰 사진을 자를 때는 미리보기만 축소하고, 선택 영역은 원본 파일에서 가져온 뒤 약 300만 화소의 소스·600만 화소의 OCR 화상으로 제한합니다. 원본 파일은 현재 탭의 메모리에만 유지합니다.
- 바르게 놓인 가로 본문의 불확실한 줄은 원본에서 최대 6줄까지 재검사합니다. 문장 길이와 편집 거리, 인식 신뢰도를 비교해 작은 개선만 채택하며, 특정 교재의 정답이나 단어 치환표를 사용하지 않습니다. 세로 본문과 크게 기울어진 사진은 이 추가 재검사에서 제외합니다.
- 독립된 생략 표시와 마지막의 명확한 괄호형 출처를 본문에서 구분합니다. 위치와 내용을 따로 표시하고 전체·단락 듣기에서는 제외합니다. 문장 속 괄호와 인용문은 유지합니다.
- 짧은 일본어 인용문의 닫는 괄호가 세로 막대로 읽힌 경우에 한해 인용부호 짝을 복원합니다. 괄호가 맞는 인용문 안의 막대와 직접 입력한 본문은 이 보정에서 제외합니다.
- 정밀 모델은 첫 다운로드와 실행에 시간이 더 필요합니다. 원근 왜곡, 작은 후리가나, 흐린 글자, 손글씨 등에서는 오류가 남을 수 있습니다.

가로쓰기·세로쓰기·혼합 지면의 생성 테스트 이미지를 실제 브라우저에서 검증했습니다. 가로쓰기 58자 테스트 한 장에서는 이전 버전의 편집 거리 8이 개선 후 0이었습니다(공백 제외). 이 수치는 해당 테스트 사진의 비교이며 전체 사진의 정확도를 보장하지 않습니다. 비교 텍스트와 실제 OCR 좌표는 tests/fixtures에 있습니다.

사용자가 제공한 실제 교재 사진으로 추가 검증했습니다. 개인 교재 이미지, 원문 전사와 OCR 전문은 저장소에 포함하지 않습니다. 작은 문항 번호, 워터마크와 밑줄에 닿은 괄호는 오류가 남을 수 있습니다.

## 후리가나와 읽기

kuromoji.js 0.1.2와 포함된 IPADIC 사전을 Web Worker에서 필요할 때만 불러옵니다. 12개 압축 사전의 크기는 약 17MiB입니다. 사전은 같은 사이트의 vendor/dict에서 제공하며 사진·본문을 후리가나 서버로 전송하지 않습니다. 사전의 저작권·라이선스는 vendor/kuromoji-NOTICE.md, 라이브러리는 vendor/kuromoji-LICENSE.txt에 포함합니다.

후리가나 버튼은 준비 중·표시 완료·실패 상태를 구분합니다. 첫 클릭 후 준비가 끝나면 추가 클릭 없이 자동으로 표시하며, 준비 중 중복 요청은 합칩니다. 초기화·본문 변경 뒤 도착한 이전 결과는 무시하고 실패한 경우에는 다시 시도할 수 있습니다.

원문 문자열과 표시용 ruby/rt 노드를 분리합니다. 복사와 음성은 원문 문자열만 사용하고, 한자·오쿠리가나를 나누어 읽는 법을 표시합니다. 후리가나 수정은 화면 표시용이며 TTS의 원문 발음을 강제로 바꾸지는 않습니다. 이름·문맥에 따라 독음이 틀릴 수 있습니다. 새 OCR을 시작할 때 후리가나 Worker를 종료해 휴대폰 메모리 사용을 줄입니다.

## Netlify

이 저장소의 main 브랜치를 Netlify와 연결합니다. 루트의 netlify.toml이 게시 폴더 sorinote를 지정합니다. 별도 빌드 명령·환경 변수·유료 API 키는 필요 없습니다. main에 수정 내용을 커밋·푸시하면 연결된 사이트가 새 버전을 배포합니다. Netlify 무료 요금제의 사용량 한도가 적용됩니다.

## 인식과 음성

Tesseract.js 6.0.1을 브라우저에서 실행합니다. 사진이나 본문을 자체 서버로 업로드하지 않습니다. 초기 엔진·언어 파일 다운로드에 인터넷이 필요합니다. 단락은 인식된 지면 배치로 구분하며, 틀린 글자나 단락은 ‘글 수정’에서 고칠 수 있습니다. 사진과 본문을 클라우드나 브라우저 저장소에 보관하지 않습니다.

Web Speech API로 기기·브라우저의 목소리를 사용합니다. 각 언어의 음성을 설치해야 할 수 있습니다. 목소리에 따라 브라우저 제공사의 온라인 음성이 사용될 수 있으며, 화면 잠금·백그라운드 동작은 기기마다 다릅니다. MP3 다운로드는 제공하지 않습니다. 일본어 단락의 한국어 자동 번역은 아래 방식으로 제공합니다.

속도 슬라이더는 input 이벤트로 배속과 게이지를 갱신합니다. Web Speech API는 이미 말하고 있는 발화의 속도 변경을 보장하지 않습니다. 현재 발화를 취소하거나 재생성하지 않고 다음 문장 또는 읽기 구간부터 최신 속도를 적용합니다. 속도 조절로 인한 끊김과 중복 발화를 피하며, 일시정지 뒤에도 기존 발화를 이어 재생합니다.

## 검증

Node.js가 있으면 다음 명령으로 단락 분리, 긴 문장 재생 분할, 단락 단독·전체 재생, 초기화 뒤 오래된 이벤트 무시, 일시정지와 예약 재생 취소를 검증할 수 있습니다.

```sh
node --test tests/*.test.cjs
```

정적 HTML·CSS·JavaScript이며 설치·빌드 없이 sorinote 폴더를 게시합니다. 자세한 사용법은 sorinote/guide.html에 있습니다.

외부 도구: [Tesseract.js](https://github.com/naptha/tesseract.js), [tessdata_best](https://github.com/tesseract-ocr/tessdata_best), Apache-2.0.

## 메뉴·번역·원본 확인·문장 연습

- ☰ 메뉴에서 본문 가져오기 / 문장 연습 / 사용 안내를 전환합니다. 페이지를 다시 불러오지 않으며 메뉴 이동은 음성을 멈추고 메모리의 자료는 유지합니다.
- 일본어 단락은 기본 접힘 상태의 한국어 뜻 보기를 제공합니다. 브라우저 Translator API의 ja→ko 지원 여부를 확인하고, 실패·미지원이면 MyMemory 익명 API를 사용합니다. 외부 전송은 처리·보관 안내에 사용자가 동의한 뒤에만 실행합니다.
- MyMemory는 선택 단락 텍스트만 GET 요청으로 받습니다. 사진·쿠키·리퍼러·이메일·API 키는 보내지 않습니다. 정책에는 문장 장기 보관, 접속 기록, 외부 기계 번역 업체 처리가 명시되어 있습니다. 문장 경계를 우선하고 각 요청을 UTF-8 480바이트 이하로 제한합니다. 익명 한도는 하루 5,000자이며 유료 전환은 없습니다.
- 번역 결과는 현재 탭의 단락별 메모리에만 캐시합니다. 수정된 단락의 결과는 무효화하고, 작업 세대와 AbortController로 늦은 응답이 새 본문을 덮지 않게 합니다. 원문 음성과 복사에는 번역을 포함하지 않습니다.
- 원본 확인은 지우기 전의 원본 캔버스와 OCR 좌표를 연결합니다. 기울기 보정 시 같은 회전 좌표의 원본을 유지합니다. 위치를 확실하게 연결하지 못하면 전체 사진을 안내합니다. 낮은 OCR 신뢰도를 강조하되 표시되지 않은 오류도 있을 수 있음을 알립니다.
- 사진 영역과 원문의 문자 범위를 각각 선택해 부분 인식하고, 미리보기를 확인한 뒤 선택한 문자만 교체합니다. 실패·취소·새 사진·편집 이후 도착한 결과는 기존 본문을 변경하지 않습니다. 합치기·문장 경계 나누기·부분 교체는 한 단계 되돌릴 수 있습니다.
- 문장 연습은 현재 단락의 원문만 사용합니다. 선택 문장 재생·반복, 2초/3초 따라 읽기 간격, 원문 가리기, 기존 후리가나와 속도 조절을 제공합니다.

브라우저 내 번역은 모든 휴대폰에서 지원되는 기능이 아닙니다. MyMemory는 브라우저에서 직접 호출하므로 제공자의 CORS·가용성·무료 한도 영향을 받습니다. 실제 교재의 추상적 용어와 인용 표현에서 두 번역 엔진 모두 오역이 확인되어, 정답 번역이 아닌 참고 뜻으로 표시합니다. 실제 휴대폰 하드웨어·통신망은 별도 사용자 확인이 필요합니다.

공식 자료: [Chrome Translator API](https://developer.chrome.com/docs/ai/translator-api), [MyMemory API](https://mymemory.translated.net/doc/spec.php), [처리·보관 정책](https://mymemory.translated.net/terms-and-conditions), [사용량 한도](https://mymemory.translated.net/doc/usagelimits.php).

### 이번 업데이트 검증

자동 테스트 66개를 통과했습니다. 실제 교재 사진 한 장은 공백을 제외한 기준 본문 770자와 일치했고 3개 단락을 유지했습니다. 이는 해당 사진만의 결과로 일반적인 OCR 정확도를 뜻하지 않습니다. 인쇄 후리가나가 있는 세로쓰기 생성 사진, 원본 위치 연결, 부분 재인식 미리보기·반영·되돌리기, 단락 합치기·나누기, 메뉴 이동 중 자료 유지, 첫 후리가나 표시, 원문만 복사, 번역 접기·다시 펼치기·편집 중 늦은 응답 무시를 확인했습니다. 실제 교재 단락으로 브라우저 내 번역과 MyMemory의 브라우저 CORS 연결을 확인했습니다. 320px·390px 화면 검증은 데스크톱 브라우저의 화면 크기 재현이며 실제 휴대폰 하드웨어·통신망 검증을 대신하지 않습니다. 개인 교재 사진과 전문은 계속 비공개 로컬 검증 폴더에만 둡니다.


## 사진과 붙여넣기 시작 화면

2026-10-28 추가: 사진 상태는 기기 내 픽셀 측정으로 밝기·대비·선명도·해상도·기울기·가장자리 잘림 가능성을 안내합니다. `읽기 좋음`일 때 자르기 창 없이 자동 인식하며, 경고가 있으면 사용자가 그대로 읽기·회전·자르기를 선택합니다. 작은 인쇄 후리가나를 사진 상태 검사에서 삭제하지 않습니다. 추정 결과이므로 잘림을 모두 검출하거나 OCR 정확도를 보장하지 않습니다.

단락의 ⋯ → 글 수정은 해당 카드의 인라인 편집기를 열며 저장·취소·한 단계 되돌리기와 원본 미리보기를 제공합니다. 변경한 단락만 새 식별자로 교체하여 번역을 갱신하고, 다른 단락의 번역 캐시와 수동 독음을 유지합니다. 새 사진·초기화·본문 교체 후 오래된 편집·비동기 결과는 반영하지 않습니다. 수정 저장은 세션 내 반영이며 디스크 보관 기능이 아닙니다.
