SORI NOTE / GETTING STARTED

내 문장으로 시작하는 듣기 연습

설치나 유료 API 키 없이 사용하는 일본어·한국어·영어 학습 도구입니다. 사진에서 글자를 추출하거나 직접 입력하고, 문장별로 들어보세요.

처음 사용하는 순서

  1. 학습할 언어를 일본어·한국어·영어 중에서 선택합니다. 언어 선택은 인식 언어와 발음을 지정하며 번역은 하지 않습니다.
  2. 교재 사진을 선택하거나 휴대폰의 촬영 버튼으로 사진을 찍습니다. 사진 없이 본문을 직접 붙여넣어도 됩니다. ‘예문 넣기’로 먼저 시험할 수 있습니다.
  3. 사진 방향을 확인하고 ‘사진에서 글자 추출’을 누릅니다. 인식 엔진과 언어 파일을 내려받는 동안 인터넷 연결이 필요합니다. 기기·사진·연결 상태에 따라 수십 초 이상 걸릴 수 있습니다.
  4. 추출된 글을 확인하고 잘못 인식한 글자와 문장부호를 고칩니다. 교재의 줄바꿈을 유지하려면 인식 전에 줄바꿈 연결 옵션을 끕니다.
  5. ‘저장하고 듣기 시작’을 누릅니다. 재생 버튼 또는 원하는 문장을 눌러 듣습니다. 반복·속도·본문 가리기를 조절해 연습합니다.
  6. 사용 후 ‘전체 백업’으로 자료를 보관합니다. 다른 기기에서 같은 주소를 연 뒤 ‘가져오기’로 백업 파일을 선택합니다.

Netlify에 올리기

올릴 폴더: sorinote
index.html, app.js, core.js, style.css, icon.svg, guide.html, _headers가 들어 있는 폴더입니다. 코드 수정이나 빌드 명령은 필요 없습니다.
  1. ZIP으로 받았다면 먼저 압축을 풉니다. index.html이 바로 안에 보이는 sorinote 폴더를 찾습니다.
  2. PC에서 Netlify에 로그인한 상태로 Netlify Drop을 엽니다.
  3. sorinote 폴더 전체를 업로드 영역에 끌어다 놓습니다. HTML 한 개만 올리지 말고 폴더 전체를 올리세요.
  4. 배포 완료 후 표시되는 https://…netlify.app 주소를 엽니다. 휴대폰에서도 같은 주소로 접속할 수 있습니다. 사용자님의 PC를 켜둘 필요는 없습니다.
  5. 사이트 이름은 Netlify의 프로젝트 설정에서 변경할 수 있습니다. 별도 도메인을 구입하지 않아도 제공된 주소를 사용할 수 있습니다.
  6. 다음 버전을 올릴 때는 기존 프로젝트의 Deploys 화면에 새 sorinote 폴더를 업로드합니다. 새 프로젝트를 만들지 않으면 같은 주소를 유지할 수 있습니다.

참고: Netlify 공식 게시 안내. 무료 요금제에는 사용량 한도가 있으므로 요금 및 사용량을 확인하세요. 이 프로그램 자체는 유료 OCR·음성 API를 호출하지 않습니다.

무료 버전의 저장 방식

자동 로그인과 기기 간 자동 동기화는 없습니다. 학습 자료·사진·마지막 재생 문장은 현재 주소의 현재 브라우저에 저장됩니다. PC의 Chrome, 휴대폰의 Safari, 시크릿 창은 서로 별개의 저장 공간입니다. 브라우저 데이터 삭제, 저장 공간 정리, 사이트 주소 변경 시 자료가 보이지 않거나 없어질 수 있으므로 백업하세요. 백업 파일에는 사진과 본문이 포함됩니다.

백업을 다른 기기로 옮겨 가져오면 자료와 마지막 문장 위치를 복원합니다. 같은 ID의 자료가 있으면 확인 후 덮어쓰고, 다른 자료는 추가합니다. 백업은 50MB, 자료는 최대 500개, 본문은 자료당 30,000자입니다. 백업이 너무 크면 사진을 제외하고 내보낼 수 있습니다.

사진 인식이 잘 안 될 때

  • 밝은 곳에서 한 페이지씩, 글자가 크게 보이게 촬영하세요. 가능하면 본문만 잘라 올리세요.
  • 사진을 똑바로 돌리고 학습 언어가 맞는지 확인하세요.
  • 인쇄된 가로쓰기 자료에 적합합니다. 세로쓰기·후리가나·복잡한 단 구성·손글씨는 오류가 생길 수 있습니다.
  • JPG, PNG, WebP를 지원합니다. HEIC는 JPG로 바꾸고, PDF는 필요한 페이지를 사진으로 저장하세요. 한 번에 사진 한 장을 처리합니다.
  • 다운로드나 인식이 실패하면 인터넷 연결과 콘텐츠 차단 설정을 확인하세요. 직접 텍스트를 붙여넣어서 계속 사용할 수 있습니다.

음성이 나오지 않을 때

  • 먼저 재생 버튼을 직접 눌러주세요. 소리 크기·무음·이어폰 연결을 확인하세요.
  • 목소리 목록이 비어 있다면 휴대폰·PC 설정에서 학습 언어의 음성/텍스트 읽어주기 데이터를 설치하세요. 설치 후 브라우저를 다시 여세요.
  • Chrome, Edge, Safari 등 음성 읽기를 지원하는 최신 브라우저를 사용하세요. 기기에 따라 목소리, 일시정지, 화면 잠금 중 재생 동작이 다릅니다.
  • 속도와 목소리 변경은 다음 문장부터 적용됩니다. 바로 적용하려면 정지 후 현재 문장을 다시 누르세요.

연결과 개인정보

사진의 글자 인식은 이 브라우저에서 Tesseract.js로 수행합니다. 프로그램은 사진과 본문을 자체 서버로 업로드하지 않습니다. 인식 도구와 언어 파일은 jsDelivr 등의 외부 배포 서버에서 내려받으므로 처음 사용 시 인터넷이 필요합니다. 음성은 기기·브라우저가 제공하며, 선택한 목소리에 따라 브라우저 제공사의 온라인 음성 서비스를 사용할 수 있습니다. 완전한 오프라인 사용을 보장하지 않습니다.

현재 버전에는 자동 번역, MP3 다운로드, 클라우드 저장, 계정 기능은 포함되지 않습니다. 무료 브라우저 음성은 녹음 파일을 생성하지 않습니다.

개발 구성과 라이선스

빌드가 필요 없는 HTML·CSS·JavaScript, IndexedDB 저장, Web Speech API 낭독, Tesseract.js 6.0.1 (Apache-2.0) 기반 글자 인식으로 구성했습니다. 인식 코드는 필요할 때만 외부 CDN에서 불러옵니다. 사용자의 API 키·결제 정보는 필요하지 않습니다.
