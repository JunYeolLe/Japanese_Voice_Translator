찍고, 고르고, 들어보세요.

사진과 본문을 따로 저장하지 않습니다. 다른 글을 듣고 싶으면 처음부터 새로를 누르거나 새 사진을 선택하세요.

사진으로 듣기

  1. 일본어·한국어·영어 중 원문의 언어를 선택하세요. 일본어는 글 방향을 자동·혼합 / 가로쓰기 / 세로쓰기 중에서 고를 수 있습니다. 우선 자동·혼합으로 읽고, 방향이 다르게 인식되면 직접 지정해주세요.
  2. 사진 찍기 또는 사진 선택을 누르세요. 선택하면 자동으로 글자를 추출합니다.
  3. 각 단락의 ▶ 버튼으로 그 단락만 듣거나, 화면 아래 전체 듣기로 끝까지 이어 들으세요.
  4. 단락이 잘못 나뉘거나 틀린 글자가 있다면 글 수정을 누르세요. 단락 사이에 빈 줄을 넣은 뒤 이 글로 듣기를 누르면 반영됩니다.

직접 입력하기

글을 직접 입력할게요에서 본문을 붙여넣고 이 글로 듣기를 누르세요. 빈 줄 하나가 단락 하나가 됩니다. 단락 안의 줄바꿈은 자연스럽게 연결합니다. 한 번에 30,000자까지 사용할 수 있습니다.

새 사진, 새 시작

새 사진을 선택하면 이전 글과 음성 재생을 정리하고 새로 추출합니다. 파일 선택을 취소하면 기존 결과를 유지합니다. 처음부터 새로는 인식 작업·사진·본문·재생 상태를 모두 비웁니다. 새로고침하거나 페이지를 닫아도 현재 자료는 남지 않습니다.

사진이 잘 읽히지 않을 때

밝은 곳에서 본문을 크게, 한 페이지씩 찍어주세요. JPG·PNG·WebP 사진을 15MB까지 지원합니다. HEIC는 JPG로 변환하고 PDF는 필요한 페이지를 사진으로 저장하세요. 가로·세로가 섞인 지면도 자동 분석합니다. 심한 원근 왜곡·그림 위 글자·후리가나·손글씨는 오류가 남을 수 있습니다. 글이 너무 작으면 본문 부분만 크게 찍어주세요. 회전 버튼은 사진을 90도 돌리고 다시 인식합니다.

사진의 단락은 원본의 글 영역, 줄·열 사이 간격과 들여쓰기를 기준으로 나눕니다. 세로쓰기는 오른쪽 열부터 읽습니다. 독립된 중략 표시는 본문 사이에 따로 표시하고, 마지막의 명확한 출처 표기는 본문과 구분해 듣기에서 제외합니다. 의미를 이해해서 자동으로 단락을 만드는 기능은 아닙니다. 잘못 나뉘면 글 수정에서 빈 줄을 추가하거나 지워주세요.

소리가 나지 않을 때

버튼을 직접 누르고 기기의 소리·무음·이어폰 설정을 확인하세요. 목소리는 기기·브라우저에서 제공합니다. 해당 언어의 음성을 설치한 뒤 브라우저를 다시 열어야 할 수 있습니다. 화면 잠금과 백그라운드에서는 기기에 따라 재생이 멈출 수 있습니다. 속도를 바꾸면 현재 단락을 처음부터 다시 읽습니다.

인식 정확도를 높인 처리

일본어는 Tesseract의 정밀 가로·세로 모델을 사용합니다. 사진을 다시 JPEG로 압축하지 않고, 작은 사진 확대와 약한 기울기 보정을 거쳐 읽습니다. 방향이 바르게 잡힌 가로 본문에서는 불확실한 줄을 원본에서 최대 6줄까지 다시 읽고, 신뢰도가 높아지는 작은 수정만 반영합니다. 글자를 임의의 정답 단어로 바꾸지는 않습니다. 짧은 일본어 인용문에서 닫는 괄호가 세로 막대로 잘못 읽히고 괄호 짝이 맞지 않을 때는 닫는 괄호를 복원합니다. 첫 사용 시 정밀 모델 다운로드 시간이 더 필요하며 휴대폰과 사진 크기에 따라 처리 속도가 다릅니다. 작은 문항 번호·후리가나·밑줄에 겹친 괄호는 오인식이 남을 수 있습니다. 오타나 단락 구분이 남으면 글 수정에서 고칠 수 있습니다.

연결 및 처리 방식

유료 API 키와 별도 서버가 필요 없습니다. 사진 인식은 Tesseract.js 6.0.1을 브라우저에서 실행하며 사진과 본문을 자체 서버에 전송하지 않습니다. 최초 인식 도구와 언어 파일 다운로드에는 인터넷이 필요합니다. 언어 파일은 브라우저에 캐시될 수 있지만 사진과 본문은 저장하지 않습니다.

음성에 따라 기기·브라우저 제공사의 온라인 음성 서비스가 사용될 수 있으므로 완전한 오프라인 사용은 보장하지 않습니다. 번역과 MP3 다운로드 기능은 없습니다. 촬영 버튼의 카메라 열기 동작은 휴대폰·브라우저에 따라 달라집니다.
