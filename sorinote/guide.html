본문만 골라, 가볍게 들어보세요.

사진과 본문은 따로 저장하지 않아요. 다른 글을 읽고 싶으면 처음부터 새로를 누르거나 새 사진을 선택하세요.

사진에서 본문 가져오기

  1. 원문의 언어를 선택하고 사진 찍기 또는 사진 선택을 누르세요.
  2. 사진 위를 드래그해 필요한 영역을 고르세요. 모서리로 크기를, 안쪽을 드래그해 위치를 바꿉니다. 세밀하게 조절에서 슬라이더를 사용할 수도 있어요.
  3. 선택 영역 읽기를 누르세요. 자르지 않으려면 전체 사진 읽기를 누르면 됩니다.
  4. 결과의 ▶로 한 단락, 화면 아래 전체 듣기로 전체를 들어보세요.

인식 후에도 사진 옆 자르기에서 원본의 다른 부분을 선택할 수 있습니다. 큰 사진은 자른 영역을 원본 해상도에서 가져옵니다. 일본어의 글 방향은 자동·혼합, 가로쓰기, 세로쓰기 중에서 고를 수 있어요.

문항 번호·밑줄·인쇄 후리가나

본문 앞의 번호, 작은 원형 문항 표시와 분리된 페이지 번호는 제외합니다. 긴 밑줄 선은 줄이고, 밑줄이 그어진 일본어 문장 자체는 유지합니다. 문장 안의 날짜·금액·소수와 일본어 장음은 지우지 않습니다.

한자 위의 작은 읽는 법, 세로쓰기 오른쪽의 작은 읽는 법을 본문과 구분해 중복 인식을 줄입니다. 화면의 후리가나는 정리된 본문에서 새로 생성합니다. 원문 교재의 특수 독음과 다를 수 있으므로 필요하면 표시된 읽는 법을 수정해주세요.

독립된 中略 표시와 마지막의 명확한 출처는 별도로 표시하고 듣기와 전체 복사에서 제외합니다. 본문 단락은 글 영역·줄 간격·들여쓰기로 구분하며 세로쓰기는 오른쪽 열부터 읽습니다.

후리가나 켜기·끄기

결과 위의 후리가나 켜기를 누르면 한자 바로 위에 히라가나가 올라갑니다. 처음 켤 때 사전 준비 시간이 필요합니다. 다시 누르면 원문만 보여요. 읽기 보조 표시를 켜도 음성과 복사에는 원문이 한 번만 들어갑니다.

작은 후리가나를 누르면 읽는 법을 수정할 수 있습니다. 이 수정은 화면의 후리가나에 반영됩니다. 실제 음성의 발음은 기기·브라우저의 일본어 목소리가 원문을 읽는 방식에 따라 달라집니다. 인명·지명·여러 독음이 있는 단어는 확인해주세요.

글자 크기와 전체 복사

읽기 설정 → 글자 크기에서 작게·보통·크게를 고르세요. 기본 본문 크기는 15px이며 후리가나가 있을 때는 줄 간격을 넓힙니다.

전체 복사는 단락 사이의 빈 줄을 유지한 본문만 복사합니다. 후리가나·출처·화면 버튼은 섞이지 않아요. 자동 복사를 사용할 수 없는 브라우저에서는 본문을 선택해 직접 복사할 수 있는 창이 열립니다.

단락 반복과 읽는 문장 표시

단락의 ↻를 누르면 해당 단락을 반복해서 읽습니다. 다시 누르면 반복을 끄고 현재 회차를 마칩니다. ▶는 한 단락을 듣거나 잠깐 멈추고 이어 듣는 버튼입니다. 정지는 반복도 함께 멈춥니다.

지금 읽는 문장은 배경색으로 표시됩니다. 긴 문장도 같은 문장 표시를 유지하면서 짧게 나누어 재생합니다. 속도를 바꾸면 현재 단락을 처음부터 다시 읽습니다.

본문 수정하기

글 수정에서 틀린 글자를 고치고 단락 사이에 빈 줄을 넣거나 지운 뒤 이 글로 듣기를 누르세요. 원문을 직접 입력할 수도 있습니다. 한 번에 30,000자까지 읽을 수 있어요. 본문을 수정하면 후리가나는 다시 켜서 생성해주세요.

사진과 음성이 잘 작동하지 않을 때

밝은 곳에서 본문을 크게, 한 페이지씩 찍어주세요. JPG·PNG·WebP 사진을 15MB까지 지원합니다. HEIC는 JPG로 변환하고 PDF는 필요한 페이지를 사진으로 저장하세요. 약한 기울기는 보정하지만 원근 왜곡·흐림·겹친 글자·아주 작은 후리가나는 오류가 남을 수 있습니다. 원본 방향이 틀리면 사진 옆 ↻로 90도 돌려 다시 읽으세요.

소리가 나지 않으면 기기의 무음·이어폰 설정과 해당 언어 음성 설치를 확인하세요. 화면 잠금과 백그라운드 재생은 기기마다 다릅니다. 자동 인식과 후리가나가 모든 사진과 단어에서 정확한 것은 아니므로 결과를 확인해주세요.

처리와 초기화

사진 인식과 후리가나 생성은 브라우저에서 처리하며 유료 API 키가 필요 없습니다. 사전과 인식 모델을 내려받을 때 인터넷이 필요합니다. 이 파일들은 캐시될 수 있지만 사진과 본문을 사이트 서버나 브라우저 저장소에 보관하지 않습니다.

새 사진을 선택하거나 처음부터 새로를 누르면 본문·사진·후리가나·반복 재생을 정리합니다. 글자 크기 설정은 현재 탭에서 유지됩니다. 사진 파일 선택 자체를 취소하면 기존 결과를 유지합니다.

음성에 따라 기기·브라우저 제공사의 온라인 음성이 사용될 수 있습니다. 번역·MP3 다운로드는 제공하지 않습니다. 촬영 버튼이 카메라를 여는 방식은 휴대폰·브라우저에 따라 다릅니다.
